## 📦 插件列表

### 1️⃣ 系统状态 `status.js`

> 🖥️ **一句话**：发送「状态」即可实时掌握机器人服务器的完整运行状况，一个指令看穿容器全貌。

| 项目 | 说明 |
| --- | --- |
| 作者 | qninq |
| 版本 | v1.0.0 |
| 分类 | 工具类 |
| 触发词 | `状态` · `系统状态` · `system` · `运行状态` |
| 优先级 | 9 |

**🚀 功能一览**

- 🔧 **处理器信息** — CPU 型号、核心/线程数
- 📊 **实时使用率** — 双采样计算 CPU 占用，内存 / 硬盘使用率
- 💽 **硬盘容量** — 总量与使用率（`fs.statfs` 优先，自动回退 `df -kP`）
- 🐧 **系统与内核** — 自动解析 `/etc/os-release`，显示发行版 + 内核版本 + 架构
- ⚙️ **进程与运行时长** — 当前进程数、系统开机时间、程序启动时间
- 🌐 **网络状态** — 网卡累计收发流量、公网 IP（3 秒超时保护）、内网 IP

**💬 回复示例**

```
【处理器】AMD EPYC 7K62 48-Core Processor
【核心数】2核心2线程
【CPU使用率】3.25%
【内存】3.8GB
【内存使用率】41.02%
【硬盘】58.4GB
【硬盘使用率】62.15%
【操作系统】debian(linux) 12
【Kernel】6.1.0(x86_64)
【主机名】sillygirl(linux)
【当前进程数】87
【开机时间】2026-09-30 08:12:45
【程序启动】2026-10-07 21:03:11
【网络收发】12.6GB / 9.4GB
【公网IP】1.2.3.4
【内网IP】172.17.0.2
```

### 2️⃣ 官方命令 `guanFangMingLing.js`

> 🤖 **一句话**：内置基础管理指令集，时间查询、版本检查、身份识别、一键更新升级重启，管理员运维必备。

| 项目 | 说明 |
| --- | --- |
| 作者 | sillyGirl |
| 版本 | v1.0.10 |
| 分类 | 工具 |
| 触发词 | `时间` · `版本` · `我是谁` · `更新` · `升级` · `重启` · `restart` |
| 优先级 | 1 |

**🚀 功能一览**

- ⏰ **时间 / time** — 当前时间、Unix 时间戳、时区
- 🏷️ **版本 / version** — 当前版本 vs 最新版本对比，自动提示是否需要更新
- 🆔 **我是谁 / myuid** — 查询自己的昵称与用户 key
- 🔄 **更新 / 升级**（仅管理员）— 拉取最新 Release 并自动重启，支持配置更新超时（10~600 秒），完成后自动向管理员推送结果
- 🔃 **restart / 重启**（仅管理员）— 1 秒后重启机器人
- 📨 **重启通知** — 更新 + 自动重启成功后，下次启动自动推送确认消息给管理员

**🔐 权限说明**：`更新` / `升级` / `restart` / `重启` 仅管理员可用，其余指令所有人可用。

**💬 回复示例**

```
SillyGirl 版本
当前版本：v0.2.3
最新版本：v0.2.4
启动时间：2026-10-07 21:03:11
状态：有新版本
```

## 🛠️ 安装方式

1. 将插件 `.js` 文件放入 SillyGirl 的插件目录（`plugins/`）
2. 重启机器人或发送 `restart`（需管理员）
3. 直接发送对应触发词即可使用
